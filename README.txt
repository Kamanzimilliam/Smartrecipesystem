Lab 1 - Windows Forms (.NET 8)
Open Lab1.csproj in Visual Studio 2022 (Windows).
In Solution Explorer double-click LoginForm.cs, ChooseForm.cs, BicycleForm.cs or MushroomForm.cs to see the Windows Forms Designer.
Press F5 to run, or use: dotnet run
